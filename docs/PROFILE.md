# 个人中心与本地评分

- 底部新增「我的」tab。当前为本地模式，不显示虚构的账号、会员信息或未实现的菜单；保留隐私政策和用户协议入口，后续接入登录及个人资料。
- 用户可选择 1 至 10 分并主动保存。记录以 `{ value, updatedAt }` 写入本机 `toolbox-rating-v1`，可再次评分覆盖，不上传服务器。
- 从首页或工具市场点击「模拟计算」时，读取本地评分：已保存 10 分进入现有模拟计算页；未评分或其他分值进入收藏夹页。原模拟集合、我的方案和收藏夹的内部功能不变。
- 评分只是当前设备上的入口选择，不承担账号鉴权或访问安全控制；本地缓存清理后会回到未评分状态。
- 微信开发者工具 CLI preview 完整编译通过（代码包 1141929 字节）；本次未接入登录或服务器，也未修改模拟集合、我的方案和收藏夹的内部数据。
