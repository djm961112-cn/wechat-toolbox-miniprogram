# 模拟计算

## 页面和本地数据

- 首页及工具市场：娱乐 → 模拟计算。
- 模拟集合：足球原生模拟器。
- 我的方案：按工具分 tab、按期号分组默认折叠，可搜索部分期号。期号及组内方案均倒序，展开后展示名称、时间、比赛、选择、赔率、过关方式、倍数、注数、金额及备注。跨期方案在涉及各期出现。
- 存储键：simulation-plans-v1。历史方案保存当时的完整选择与赔率快照，不随赛事接口更新改变。

## 数据接口

使用官方网页同源公开接口：

https://webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry?channel=c

channel 必须是 c，与网页 commonV1Fun.comDataChannel 保持一致。其他渠道可能使 single/allUp 字段变化。

每次进入足球页面重新查询，不使用本地旧赛事兜底。刷新清空选择，避免把旧赔率混进新数据。网络失败保留重试入口。

查询携带防缓存时间戳，页面分别显示精确到秒的本次查询时间与官方 lastUpdateTime；官方数据更新时间可能早于查询时间。未开放、停售或没有单串关许可的赛事保留展示，选项置灰且事件层禁止选择。

上线前在微信公众平台「开发管理 → 开发设置 → 服务器域名」把 https://webapi.sporttery.cn 配置为 request 合法域名。项目保持 urlCheck=true。外部接口可用性和微信后台域名配置不能由代码保证。

## 玩法与计算

胜平负 HAD、让球胜平负 HHAD、总进球 TTG、半全场 HAFU、比分 CRS、混合玩法。

- 胜平负页同时展示普通 [0] 与让球 [+n/-n] 两行；缺失玩法及缺失赔率显示禁用的 -。仅有让球玩法的比赛也保留。
- 同场允许 HAD、HHAD 等多个玩法同时选择，同一玩法也允许复选。逐注组合每场仅取一个玩法的一个结果，不把同场两个玩法当作两个串关场次。
- 切换不同顶部玩法（如胜平负 → 总进球）清空比赛选项、过关方式、金额和未保存预览；点击当前玩法不清空。倍数保留，已保存方案不受影响。
- 底部固定展示场数、过关选择、倍数、注数、投注金额和理论金额区间。过关列表在底栏上方弹出，不再滚到比赛列表底部。
- 赔率和 single/allUp 资格逐场逐玩法读取，不把整场资格写死。
- 单关仅计算有单关资格的所选项；其余串关选择保留，不能算入单关。
- 过关方式与官方 allUpList 相交；页面只支持自由过关多选（单关、2串1至8串1），不提供组合过关。旧组合方案仍能查看历史明细。
- 2 场默认 2串1、3 场默认 3串1，依次类推；不支持对应关数时使用最高可用过关方式。增减场数恢复默认，同一场数下保留有效的手动增减选择；手动全部取消后不强行选回。
- 串关场数限制与网页一致：HAD/HHAD 8，TTG 6，HAFU/CRS 4；一组最多选 8 场。
- 同场不同玩法只算同一场，不作为两个独立串关场次。
- 注数按组合与各场选项数量精确计算，每注 2 元。
- 理论金额区间是至少中一注时整个方案的最低、最高税前奖金，未中奖的 0 元不计入。逐场枚举兼容的全场比分及半场赛果，用过关拆分的场次组合求整个方案总奖金；多种过关方式同时中奖时累加。
- 最低奖金保留可输与可赢的结果状态；如果某场选项覆盖全部赛果，不能假设该场所有选项都未中。最高奖金也采用同一个兼容赛果，不能把互斥玩法的独立最高赔率相加。
- 区间未计逐注舍入、奖金限额及税费。高赔率组合可能触及逐注限额时在保存后的明细另作提示。逐注明细延续限额和舍入处理，不能视为出票或兑奖结果。
- 方案预览采用居中简洁弹窗，仅展示过关方式、比赛及选项赔率；点击保存再填写名称和备注。已保存方案的「明细」展示金额、倍数、完整比赛选择、数据时间、备注和逐注组合（每次 30 注）。明细仅读取本地快照，不请求最新赛事，也不重算历史总奖金。
- 「清空」位于底部方案预览左侧，未选比赛或正在刷新时禁用；点击后清空比赛、过关方式和预览，不删除已保存方案。
- 比赛日期和时间已随比赛选择保存在本地快照，方案列表和明细均展示该缓存时间，不以当前赛事接口覆盖历史时间。
- 预览、我的方案和明细中的选项采用方框，同玩法一行、不同玩法分行；仅展示选项、让球数与赔率，不展示玩法名称及 [仅串关]/[可单关] 标签。旧快照也按结构化 selections 字段生成新样式，不重写本地存储。
- 选项为独立小格子，每格最大宽 176rpx。每场按其最宽一行的选项数设置 1 至 3 列，整个区域居中；该场每行使用相同列数，短行从第一列开始，保留右侧空位。长内容换行，窄屏可缩小列宽，单选不拉伸铺满整行。
- 我的方案列表的选项区域单独居左，和比赛名称、时间对齐；预览和明细仍整体居中，格子宽度及组间距保持一致。
- 同场不同玩法组之间留白 24rpx，同一玩法内部格子间距 8rpx；预览高度包含组间留白，过长时滚动展示。
- 明细按过关方式、比赛集合及逐场所选玩法分组。例如 001 胜/平和让平、002 胜，生成普通胜平负组合（2 注）和让球组合（1 注），不合成同场两个结果同时命中的一注。奖金区间仍按兼容的真实赛果计算。

本模块没有交易、购买、付款功能。
