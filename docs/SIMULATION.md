# 模拟计算

## 页面和本地数据

- 首页及工具市场：娱乐 → 模拟计算。
- 模拟集合：足球原生模拟器。
- 我的方案：按工具分 tab，创建时间倒序，展示名称、时间、比赛、选择、赔率、过关方式、倍数、注数、金额、参考最高返回及备注。
- 存储键：simulation-plans-v1。历史方案保存当时的完整选择与赔率快照，不随赛事接口更新改变。

## 数据接口

使用官方网页同源公开接口：

https://webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry?channel=c

channel 必须是 c，与网页 commonV1Fun.comDataChannel 保持一致。其他渠道可能使 single/allUp 字段变化。

每次进入足球页面重新查询，不使用本地旧赛事兜底。刷新清空选择，避免把旧赔率混进新数据。网络失败保留重试入口。

上线前在微信公众平台「开发管理 → 开发设置 → 服务器域名」把 https://webapi.sporttery.cn 配置为 request 合法域名。项目保持 urlCheck=true。外部接口可用性和微信后台域名配置不能由代码保证。

## 玩法与计算

胜平负 HAD、让球胜平负 HHAD、总进球 TTG、半全场 HAFU、比分 CRS、混合玩法。

- 赔率和 single/allUp 资格逐场逐玩法读取，不把整场资格写死。
- 单关仅计算有单关资格的所选项；其余串关选择保留，不能算入单关。
- 过关方式与官方 allUpList 相交；支持自由多选及一种组合过关加单关。
- 串关场数限制与网页一致：HAD/HHAD 8，TTG 6，HAFU/CRS 4；一组最多选 8 场。
- 同场不同玩法只算同一场，不作为两个独立串关场次。
- 注数按组合与各场选项数量精确计算，每注 2 元。
- 参考最高返回通过兼容的全场比分及半场赛果估算，同场相斥结果不会同时计为获胜。
- 高赔率逐注限额、奖金舍入与税费可能使实际返回低于参考值，页面明确显示为税前估算上限，不能视为出票或兑奖结果。

本模块没有交易、购买、付款功能。

## 验证

已核对实时官方 feed 的五个玩法、单关/串关标记及过关列表；node tests/football-simulation.test.js 通过固定赔率的注数、全部组合过关、混合相斥结果、逐注分页、快照排序及保存失败检查。

官方响应样本驱动的页面集成检查通过：刷新 → 选择 → 过关 → 预览 → 保存，以及重复保存保护、历史赔率不变和域名错误状态。开发者工具 CLI preview 编译成功；集合页、足球页及悬浮按钮已在模拟器打开检查。

当前模拟器实际请求被合法域名校验拦截，未关闭校验。需在微信后台配置 request 合法域名后完成真机实时加载检查。外部域名和审核配置仍是上线前置条件。
