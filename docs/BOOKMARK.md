# 单网址收藏夹

- 首页与工具市场的「个人日常」新增收藏夹入口。当前只保存一条 http/https 网址，未保存时显示新增表单；保存后显示网址，支持复制、更换与删除。
- 使用本地存储键 `bookmark-url-v1`，记录固定 ID、网址及创建/更新时间。当前版本不调用运营者服务器，也不自动访问或抓取用户输入的网址。
- 小程序 `web-view` 只能打开已配置并校验的业务域名。用户的服务器域名尚未配置，当前只展示和复制网址；后续是否提供页内访问应按小程序主体能力、业务域名及内容审核结果确定。
- 接入云端同步前，需补充身份校验、隐私指引和本地数据迁移。原「模拟计算」代码与入口保持不变。
- 微信开发者工具 CLI preview 编译通过（代码包 1135277 字节）。此次未接入服务器，也未在小程序中打开外部网页。
