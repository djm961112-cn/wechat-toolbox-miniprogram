# 发布与后端接入路线

## 第一阶段：无服务器发布

1. 在微信开发者工具中使用已备案的小程序 AppID 导入并预览。
2. 通过体验版邀请测试，再按公众平台流程提交审核和发布。
3. 此阶段只启用无需联网的工具，不申请域名、不部署 API。

## 第二阶段：确有联网需求时

先确认数据类型、用户隐私、调用方和预计调用量，再选择微信云开发/CloudBase 等托管服务。配置服务端身份校验、访问控制、数据最小化、日志脱敏、配额告警和备份策略。小程序 AppSecret 与第三方服务密钥只能放服务端。

新增公网 `wx.request` 前，先在公众平台配置 HTTPS 合法域名并按适用规则完成备案；在开发者工具中开启 URL 校验进行真机验证。不要依赖开发工具的“不校验合法域名”选项作为上线方案。

## 版本发布

Git 分支建议：`main` 对应可发布版本，功能开发使用 `feat/<简短名称>`。每次提审前记录版本号、改动摘要、隐私/权限变化和回滚版本。GitHub Actions 可以做 JSON/静态检查，但上传体验版通常需要小程序上传密钥；后续接 CI 时使用仓库密钥管理，不要将密钥提交到仓库。
